# Snow & Lead — Night Debt · C# / Blazor

Учебная однопользовательская 3D-игра для браузера. Игрок исследует зимний город, сражается с противниками и выполняет миссию. Правила ресурсов, очков, сложности и прогресса выполняются на C#; интерфейс построен на Blazor WebAssembly; Three.js отвечает за трёхмерный мир.

**Автор: Alihan Kokey. Группа: IT-2502.**

Проект подготовлен на основе предоставленной игры; Three.js используется по лицензии MIT. К защите нужно уметь объяснить код и границы C# / JavaScript.

## Что сдавать

В финальном ZIP предусмотрены:

- `Source/` — исходники C# / Razor / JavaScript, проекты и тесты;
- `Play/` — опубликованная версия для локального HTTP-сервера;
- `START_GAME.cmd` и `serve.py` — запуск опубликованной игры в Windows через Python 3;
- `docs/` — архитектура, сопоставление с требованиями и сценарий защиты;
- `verification/` — итоговый отчёт сборки и проверок.

Точный состав и фактические результаты смотреть в итоговом отчёте архива. Наличие тестов в исходниках само по себе не означает, что все проверки пройдены.

## Быстрый запуск опубликованной версии

1. Полностью распаковать ZIP в обычную папку.
2. Запустить `START_GAME.cmd`. Для этого нужен установленный Python 3.
3. Оставить окно локального сервера открытым и открыть показанный адрес в браузере.

Blazor WebAssembly нужно загружать по HTTP. Двойной щелчок по `Play/index.html` с адресом `file://` для этой версии не подходит. .NET SDK и Node.js для игры из `Play/` не нужны. Публичная ссылка на хостинг в комплект не входит.

Для телефона подключить его к той же Wi-Fi-сети и открыть адрес компьютера из окна сервера, например `http://192.168.1.10:8767/`. `127.0.0.1` на телефоне указывает на сам телефон. Для доступа из локальной сети серверу может потребоваться разрешение Windows в частной сети. Гостевые сети иногда изолируют устройства.

## Управление

| Компьютер | Телефон / планшет |
|---|---|
| WASD — движение | Левый джойстик — движение |
| Мышь — обзор | Правая часть экрана — обзор |
| Mouse1 — огонь; удержание — серия выстрелов | Удерживать **FIRE** и вести этим же пальцем для стрельбы и прицеливания |
| Shift — бег | **SPRINT** — переключить бег |
| R — перезарядка | **RELOAD** — перезарядка |
| Space / Q / правая кнопка — замедление | **SLOW** — замедление |
| Esc / P — пауза | Кнопка паузы сверху слева |

Если захват курсора недоступен, удерживать левую кнопку мыши и двигать мышь. При потере фокуса игра ставится на паузу. Качество графики, звук, чувствительность и способ управления доступны в настройках. Сложность выбирается перед новой игрой.

## Запуск и проверка исходников

Нужен .NET 10 SDK. Команды выполнять из корня исходного проекта, где находится `src/` (в архиве — `Source/`). Первое восстановление NuGet-пакетов может требовать интернет.

```powershell
dotnet run --project src/SnowAndLead.Client --urls http://0.0.0.0:8765
dotnet test tests/SnowAndLead.Core.Tests
dotnet publish src/SnowAndLead.Client -c Release -o publish
```

Публикация создаёт статические файлы в `publish/wwwroot/`; их нужно обслуживать HTTP-сервером. Первый запуск игры проверять на компьютере; затем использовать его IP-адрес на телефоне.

## Где находятся главные части

- `src/SnowAndLead.Core/GameSession.cs` — `GameSession`, `GameSnapshot`, `GameRules`: здоровье, патроны, таймеры, очки, миссия и статистика.
- `src/SnowAndLead.Client/` — Razor-компоненты, сервис `GameInterop`, стили и браузерные ресурсы.
- `src/SnowAndLead.Client/wwwroot/` — Three.js, сцена, камера, сенсорный ввод, звук и локальные ресурсы.
- `tests/SnowAndLead.Core.Tests/` — модульные тесты правил на xUnit.
- `docs/ARCHITECTURE.md` — распределение ответственности и поток данных.
- `docs/REQUIREMENTS.md` — все 20 критериев и ограничения.
- `docs/DEFENSE_GUIDE.md` — подготовка к защите на 15–20 минут.

Прогресс — лучший счёт, число смертей и побед в текущем браузере. Полное состояние уровня и позиции противников не сохраняется. Игра использует гибрид C# и JavaScript: перенос всех вычислений сцены в C# в объём работы не входит. Облачного сервиса, аккаунтов, SignalR и сетевого режима нет. Проверки на размерах мобильного экрана не заменяют испытания на физических устройствах.
